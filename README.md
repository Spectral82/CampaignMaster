# CampaignMaster — сервис управления рассылками

Веб-приложение на Django 5 для создания, управления и запуска
email-рассылок клиентам с учётом ролей пользователей и статистики.

## Функциональность

- **Клиенты** — добавление, просмотр, редактирование и удаление получателей рассылки (email, Ф. И. О., комментарий).
- **Сообщения** — управление темами и текстами писем.
- **Рассылки** — создание рассылок с периодом действия; статус («Создана» / «Запущена» / «Завершена») вычисляется динамически по текущему времени.
- **Отправка** — вручную из интерфейса или командой `python manage.py send_mailing <id>`; письма уходят каждому получателю через `send_mail()`.
- **Попытки рассылок** — история отправок со статусом и ответом сервера; записи создаются пакетно (`bulk_create`).
- **Главная страница** — число всех рассылок, активных рассылок и уникальных клиентов.
- **Статистика** — успешные и неуспешные попытки, количество отправленных писем по рассылкам пользователя.
- **Роли** — пользователь управляет только своими данными; менеджер просматривает все данные, блокирует пользователей и отключает рассылки.
- **Аутентификация** — регистрация с подтверждением email, вход, выход, восстановление пароля.
- **Кеширование** — серверное (`cache_page`, `get_or_set`) и клиентское (`Cache-Control`) для главной и статистики.

## Технологии

Python 3.11+, Django 5.2, PostgreSQL, python-dotenv.

## Запуск проекта

```bash
# 1. Создать и активировать виртуальное окружение
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # Linux/macOS

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Заполнить .env (шабон переменных ниже)

# 4. Применить миграции
python manage.py migrate

# 5. Создать суперпользователя
python manage.py createsuperuser

# 6. Запустить сервер
python manage.py runserver
```

Сервис доступен на `http://127.0.0.1:8000/`.

## Переменные окружения (.env)

```
DB_NAME=имя_базы
DB_USER=пользователь
DB_PASSWORD=пароль
DB_HOST=localhost
DB_PORT=5432
DJANGO_SECRET_KEY=секретный_ключ
DJANGO_DEBUG=True
EMAIL_HOST_USER=почта_отправителя
EMAIL_HOST_PASSWORD=пароль_приложения
```

## Структура проекта

- `campaignmaster/` — настройки проекта
- `users/` — регистрация, аутентификация, права и роли
- `mailings/` — клиенты, сообщения, рассылки, попытки отправки, статистика
- `main/` — главная страница
- `templates/` — общие шаблоны и шаблоны аутентификации
